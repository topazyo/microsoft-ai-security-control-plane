# Security & Confidentiality

This repository is public and built entirely from public primary sources and a
synthetic/lab environment (see `disclaimer.md` and the README's Confidentiality
note). When creating or editing any content here:

- Never add organization names, tenant/directory/workspace GUIDs, subscription
  GUIDs, hostnames, user names, emails, internal URLs, IP addresses, logs,
  screenshots, or license counts.
- Never add NDA or private-preview-program material.
- Never hardcode secrets, tokens, passwords, API keys, certificates, or private
  keys — this applies even in examples or scratch content.
- If content can only be verified against a private tenant or NDA source, mark
  the row **Requires further validation** rather than including the private
  detail.
